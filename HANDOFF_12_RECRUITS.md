## Technical Implementation

### Spec-Lock System

Each companion has `spec` field that becomes `char.locked_spec` on recruitment. They still earn talent points but only one tree (their class specialization) is spendable. This is **permanent identity** - they're not respec'able.

### NPC Color Rendering

1. **RecruitNPC** now loads `npc_color` field (hex string like `#FF6B6B`)
2. **TilemapRenderer** converts hex to RGB and draws recruits in color
3. **OverworldScreen** passes recruits list to renderer alongside vendors
4. Result: Bright, distinctive colors pop on map vs gold vendors

### Backgrounds

All backstories shortened to fit UI box without overflow. Each still conveys:
- Earth origin + profession
- Why they came to frontier
- Current role/goal
- Personality quirk
