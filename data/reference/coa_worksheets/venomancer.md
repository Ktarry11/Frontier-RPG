# Venomancer - CoA reference vs ours

- CoA talents: **177**
- already in our data by name: **48** (of those, **26** are pure scalars on our side)
- not in our data at all: **129**
- single-clause scalars in CoA's own tree: **34** (19%)
- carry real-time assumptions needing translation: **91** (51%)
- without an extracted CoA icon: **2**

Source: data/reference/coa/venomancer.json (Ascension CoA Builder payload, the same data allthingscoa.com presents).

`MATCH` - we already have a talent of this name. `scalar` means ours is a pure numeric bonus, which is the thing being replaced. `needs` lists the engine mechanic CoA's version wants; every one listed is a system this engine already has.
