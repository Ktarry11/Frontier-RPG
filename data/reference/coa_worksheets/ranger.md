# Ranger - CoA reference vs ours

- CoA talents: **135**
- already in our data by name: **64** (of those, **50** are pure scalars on our side)
- not in our data at all: **71**
- single-clause scalars in CoA's own tree: **31** (22%)
- carry real-time assumptions needing translation: **70** (51%)

Source: data/reference/coa/ranger.json (Ascension CoA Builder payload, the same data allthingscoa.com presents).

`MATCH` - we already have a talent of this name. `scalar` means ours is a pure numeric bonus, which is the thing being replaced. `needs` lists the engine mechanic CoA's version wants; every one listed is a system this engine already has.
