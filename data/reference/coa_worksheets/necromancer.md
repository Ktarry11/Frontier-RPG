# Necromancer - CoA reference vs ours

- CoA talents: **117**
- already in our data by name: **66** (of those, **52** are pure scalars on our side)
- not in our data at all: **51**
- single-clause scalars in CoA's own tree: **21** (17%)
- carry real-time assumptions needing translation: **58** (49%)

Source: data/reference/coa/necromancer.json (Ascension CoA Builder payload, the same data allthingscoa.com presents).

`MATCH` - we already have a talent of this name. `scalar` means ours is a pure numeric bonus, which is the thing being replaced. `needs` lists the engine mechanic CoA's version wants; every one listed is a system this engine already has.
