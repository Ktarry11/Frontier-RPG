# Bloodmage - CoA reference vs ours

- CoA talents: **159**
- already in our data by name: **77** (of those, **68** are pure scalars on our side)
- not in our data at all: **82**
- single-clause scalars in CoA's own tree: **28** (17%)
- carry real-time assumptions needing translation: **74** (46%)
- without an extracted CoA icon: **1**

Source: data/reference/coa/bloodmage.json (Ascension CoA Builder payload, the same data allthingscoa.com presents).

`MATCH` - we already have a talent of this name. `scalar` means ours is a pure numeric bonus, which is the thing being replaced. `needs` lists the engine mechanic CoA's version wants; every one listed is a system this engine already has.
