# Cultist - CoA reference vs ours

- CoA talents: **162**
- already in our data by name: **65** (of those, **6** are pure scalars on our side)
- not in our data at all: **97**
- single-clause scalars in CoA's own tree: **29** (17%)
- carry real-time assumptions needing translation: **70** (43%)
- without an extracted CoA icon: **3**

Source: data/reference/coa/cultist.json (Ascension CoA Builder payload, the same data allthingscoa.com presents).

`MATCH` - we already have a talent of this name. `scalar` means ours is a pure numeric bonus, which is the thing being replaced. `needs` lists the engine mechanic CoA's version wants; every one listed is a system this engine already has.
