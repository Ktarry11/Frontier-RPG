# Icon generation prompts — 3 × 48 = 144

135 icons are needed right now (100 abilities + 35 named passives). Three sheets of 48 covers it with 9 spare.

Each sheet is grouped so one prompt produces a visually consistent set. Paste one prompt per conversation; don't mix sheets.

**Style note:** these describe an original painterly fantasy-game icon style. Don't ask the model to copy any existing game's art — ask for the style and the subject, which is what's below.

---

## Shared style preamble (already included in each prompt)

> Generate a sheet of 48 fantasy RPG ability icons, arranged as an 8 × 6 grid, each cell a complete square icon.
>
> Style: painterly digital illustration, high contrast, dramatic rim lighting against a dark background, saturated colour, heavy black outline around each icon, slight bevel. Each icon has ONE clear centred subject with a strong readable silhouette — these are displayed at 64 × 64 pixels, so no fine detail, no text, no letters, no numbers, no borders inside the art. Think classic MMO spellbook art: bold shapes, glowing edges, deep shadow.
>
> Keep the palette consistent across the whole sheet.
