# Trait and Sworn skill icons: seven sheets

Kyle, 21 Nov 2026: "we do need icons for all the new character traits...and i guess all the sworn skills." 138 traits
and 109 Sworn skills have no icon and show a plain square. Each icon comes from the line in the recruit's profile the skill
was built from, so it shows that person's story rather than a stock spell.

Attach two or three existing trait icons as the style reference (any of `assets/icons/abilities/personal_adrian_*.png` or
`personal_alonso_*.png`): full-bleed painted ability icons, one subject, warm light, a dark frame.

Each sheet is sliced by `tools/asset_pipeline/slice_ability_icons.py` (the command is under each block). Sworn icons are the
same style with a thin glowing gold ring round the edge, so a Sworn skill reads as special on the bar.
